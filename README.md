# Xmsg

Aplicativo web de mensagens em tempo real com perfis pesquisáveis, conversas, links, imagens e arquivos de até 5 GB.

## Site

https://conversa-silva.silvapietro434.chatgpt.site

## Recursos

- Login pelo ChatGPT e perfil persistente
- Busca por nome de usuário e conversas entre pessoas
- Mensagens, links, imagens e arquivos
- Upload multipart com progresso, cancelamento e tentativas automáticas
- Personalização de avatar, bio, cor, fundo e densidade do layout
- Interface responsiva em estilo escuro com vidro e aurora

## Desenvolvimento

```bash
npm install
npm run dev
```

Para validar a versão de produção:

```bash
npm run lint
npm run build
```
